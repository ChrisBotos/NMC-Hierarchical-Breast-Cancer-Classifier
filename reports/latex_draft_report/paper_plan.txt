RESEARCH QUESTION
-----------------
Wessels et al. (2005) demonstrated that simple classifiers with univariate
feature filtering outperform complex pipelines on continuous expression data.
When classifying breast cancer molecular subtypes (HER2+, HR+, Triple Negative)
from discrete, high-dimensional aCGH copy-number profiles with limited sample
size, does this principle hold, and how do feature redundancy and multi-class
structure affect classifier selection?

GOALS
-----
- Answer the research question with evidence from both flat and hierarchical
  experiments
- Show that the answer DEPENDS on problem structure: RF > NMC flat, NMC > RF
  hierarchical - this is conditionality, not vindication of Wessels
- Present the hierarchical model as the primary result (what the classifier
  does, how well it works) and use Wessels as the interpretive lens
- Show that correlation-based merging is a principled preprocessing step
  inspired by CGHregions
- Identify chr17q12 (ERBB2/HER2 amplicon) as the best single biomarker
- Report honest accuracy estimates with appropriate statistical tests
- Produce 3 publication-quality figures/tables, holding a 4th slot for revision
- Explicitly explain draft-to-final changes and the accuracy estimate derivation

METHODS
-------
Subsection: Data description
  - 100 labelled training samples, 57 unlabelled validation samples
  - 244K aCGH platform, segmented into 2834 genomic regions
  - CN calls: -1 (loss), 0 (normal), 1 (gain), 2 (amplification)
  - class distribution: 32 HER2+, 36 HR+, 32 TN (approximately balanced)
  - hg18/NCBI36 coordinates

Subsection: Label-free region merging
  - motivation: adjacent spatial autocorrelation r=0.92 within 0.1 Mb
  - cite CGHregions (van de Wiel & van Wieringen 2007) as methodological
    precedent for label-free dimension reduction of aCGH data
  - algorithm: greedy one-pass per chromosome, merge adjacent if r > 0.8
  - threshold justification: 91% of adjacent pairs have r > 0.8 (same CN
    event spanning multiple probes); 4.4% have r < 0.7 (genuinely distinct)
  - result: 2834 regions -> 273 consensus segments (90% reduction)
  - representation: median CN of constituent regions per sample
  - signal preservation: top KW features unchanged, PCA structure preserved
  - LEAKAGE DEFENSE (must appear in paper text):
    Merging is performed once on all 100 training samples before CV splits.
    This means merged feature definitions are informed by test-fold CN values.
    However, the operation is:
    (a) label-free (no class information used),
    (b) approximately stable across subsamples - TODO: run merging on 5-10
        random 80% subsamples and report Jaccard overlap of segment boundaries
        against full-data merging; if overlap > 0.95, cite as evidence; if not,
        discuss implications, and
    (c) consistent with CGHregions, which performs the same global preprocessing
        before any supervised analysis.
    This is distinct from the Ambroise & McLachlan (2002) violation, which
    involves label-dependent feature selection outside CV folds.
    If the stability analysis is not run, soften (b) to: "we expect the
    operation to be approximately stable across subsamples given the strong
    adjacent autocorrelation (r = 0.92), though we did not formally quantify
    this."
  - merging map is saved as part of the model artifact and applied to
    validation data in run_model.py (same segment boundaries for train and
    validation; validation data is NOT re-merged independently)

Subsection: 2x2 experimental design
  - table: (KW, EN) x (NMC, RF)
  - KW: Kruskal-Wallis H-statistic ranking, top-k selection, cite KW (1952)
    - why appropriate: non-parametric, ordinal CN values, 3-class natively
    - hyperparameter: k (tuned via inner CV)
  - EN: Elastic Net logistic regression, cite Zou & Hastie (2005)
    - L1+L2 penalty, grouping effect for correlated features
    - hyperparameters: C, l1_ratio (tuned via inner CV)
  - NMC: Nearest Mean Classifier (centroid-based)
    - zero hyperparameters, linear decision boundary
    - directly referenced by Wessels et al.
  - RF: Random Forest, cite Breiman (2001)
    - 500 trees, fixed hyperparameters (not tuned to avoid inner CV overfit)
    - non-linear, captures feature interactions

Subsection: Hierarchical classifier
  - motivation: flat experiment revealed HER2+ recall = 1.000 across all 4
    pipelines; real accuracy bottleneck is HR+ vs TN confusion
  - dedicated 2-class KW ranking (HR+ vs TN only) surfaces different features:
    chr12q (23/30), chr5q (7/30) instead of chr17 ERBB2
  - architecture:
    - Stage 1: HER2+ vs rest, KW+RF k=5, fixed threshold 0.5 (no tuning)
    - Stage 2: HR+ vs TN, one of the 4 pipeline variants with inner CV tuning
  - Stage 1 achieved BA = 1.000 in all 1000 outer test folds (200 repeats x
    5 folds) with threshold fixed at 0.5. This is plausible because the top
    KW features are from chr17 (4 of 5) and chr12 (1 of 5). The strongest
    feature spans the ERBB2 amplicon on chr17q12 (H = 73.9, p = 9e-17);
    the remaining four have H = 22-26, still highly significant. HER2+
    samples show CN = 2 (amplification) at these loci while non-HER2+
    samples show CN = 0 or -1. The RF probability threshold at 0.5 sits
    in a wide margin between perfectly separated class scores.

Subsection: Cross-validation scheme
  - nested stratified repeated 5-fold CV
  - outer loop: unbiased BA estimation
    - flat experiment: 50 repeats x 5 folds = 250 evaluations
    - hierarchical experiment: 200 repeats x 5 folds = 1000 evaluations
  - inner loop: 5-fold CV on outer training set for hyperparameter tuning
  - feature selection performed INSIDE each outer fold to prevent information
    leakage (cite Ambroise & McLachlan 2002, Wessels et al. 2005)
  - scoring metric: balanced accuracy (macro-averaged recall)
  - FIGURE 1: workflow diagram showing nested CV + hierarchical architecture

Subsection: Statistical comparison
  - Friedman test for overall pipeline differences
  - Nadeau-Bengio corrected t-test for formal pairwise claims (cite Nadeau &
    Bengio 2003) - appropriate for repeated CV because it corrects for the
    non-independence of overlapping folds
  - paired bootstrap CIs (10,000 resamples) as pragmatic distinguishability
    measure when Nadeau-Bengio is overly conservative
  - cite Bouckaert & Frank (2004) for discussion of CV test pitfalls
  - NOTE: do NOT report Wilcoxon p-values in the paper. Wilcoxon treats
    CV repeats as independent and overstates significance. Bootstrap CIs
    provide the directional evidence; Nadeau-Bengio provides the formal test.
    Wilcoxon results stay in internal findings.md only.

Subsection: Final model training and deployment
  - final model retrained on all 100 samples using the plateau configuration
    identified by nested CV (no hyperparameters re-tuned)
  - plateau ensemble: average predictions from the top ~15 near-optimal
    hyperparameter configurations, identified from pooled inner CV scores
  - plateau threshold formula and ensemble size cap were fixed before observing
    outer-CV results (not selected by iterating on outer BA)
  - merging map saved as part of the model artifact; applied to validation data
    in run_model.py to produce the 273 consensus segments before prediction

RESULTS
-------
Subsection: Flat 2x2 experiment
  - TABLE (part of main results table): 4 pipelines, mean BA, std, per-class
    recall, mean features selected
  - KW+RF best (BA = 0.791), KW+NMC worst (BA = 0.631)
  - RF >> NMC regardless of feature selector (+16 pp for KW, +2.4 pp for EN)
  - feature selector matters less: KW vs EN only ~2 pp difference for RF
  - Nadeau-Bengio: only KW+NMC vs KW+RF significant after correction
  - HER2+ recall = 1.00 across all 4 pipelines -> the real bottleneck is
    HR+/TN confusion (TN recall = 0.62-0.64)
  - this motivates the hierarchical approach (one tight paragraph, not a
    dramatic act break)

Subsection: Hierarchical classifier results
  - TABLE 1 (main results table): combine flat + hierarchical in one table
    - columns: pipeline, Stage 2 BA (BA2), combined 3-class BA, per-class
      recall (HER2+, HR+, TN), mean features selected
    - flat results in top rows, hierarchical in bottom rows
  - NMC > RF reversal (bootstrap CIs exclude zero for all NMC-vs-RF pairs)
  - EN+NMC(plateau) best overall: BA2 = 0.759, combined BA = 0.840
  - Nadeau-Bengio: all pairwise comparisons n.s. (conservative correction)
  - bootstrap CIs: 38/45 pairs distinguishable at 95% level
  - FIGURE 2: violin/box plot showing BA distributions for flat vs hierarchical
    pipelines, with significance brackets (bootstrap CIs)

Subsection: Plateau ensembling
  - EN+NMC base BA2 = 0.729 -> EN+NMC(plateau) BA2 = 0.759 (+3.0 pp)
  - mechanism: inner CV on n~11 cannot reliably rank 800 EN+NMC hyperparameter
    combinations; single-best selection is noisy
  - plateau ensemble averages over near-optimal configs, stabilising predictions
  - gain scales with grid size: 800 combos -> +3.0 pp, 32 combos -> +1.4 pp
  - leakage defense: leave-one-repeat-out plateau membership overlap is 14.9/15
    -> removing any single repeat barely changes the plateau
  - CAVEAT (qualitative, no fake precision): the plateau gain may be modestly
    inflated by indirect dependence between the inner-CV-derived plateau
    threshold and outer-CV scores. We do not attempt to quantify this
    inflation precisely; the leave-one-repeat-out analysis suggests it is
    small relative to the +3.0 pp total gain.

Subsection: Merging threshold sensitivity (one sentence in Results text)
  - r=0.7/0.8/0.9 all give similar Stage 2 BA (within ~2 pp, not significant)
  - only raw (no merging) is significantly worse (-7 pp, p=0.008)
  - conclusion: merging helps, but the exact threshold is not a sensitive
    hyperparameter. One sentence in Results, not a table.

Subsection: Single best biomarker region
  - chr17q12 (ERBB2/TCAP locus), KW H = 73.9, p = 9e-17
  - standalone performance: perfectly separates HER2+ from rest (Stage 1
    uses only 5 features from this locus and achieves BA = 1.000)
  - cannot distinguish HR+ vs TN alone (different genomic signal on chr12q/5q)
  - biological context: ERBB2 amplification is the defining molecular event
    of the HER2+ subtype, directly targeted by trastuzumab; cite Slamon (1987)

Subsection: Accuracy estimate derivation
  - the correct formula for expected correct predictions is NOT BA x N
  - BA = macro-averaged recall = mean of per-class recalls
  - expected correct = sum over classes of (recall_c x n_c_in_validation)
  - since validation class proportions are unknown, we use training proportions
    as the best available proxy:
      expected = (32/100 x 1.00 + 36/100 x 0.78 + 32/100 x 0.74) x 57
               = (0.320 + 0.281 + 0.237) x 57
               = 0.838 x 57
               = 47.8 -> estimate = 48
  - sensitivity analysis under alternative proportions:
    - uniform (19/19/19): 19x1.00 + 19x0.78 + 19x0.74 = 47.9 -> 48
    - skewed (10/30/17):  10x1.00 + 30x0.78 + 17x0.74 = 46.0 -> 46
    - skewed (20/20/17):  20x1.00 + 20x0.78 + 17x0.74 = 48.2 -> 48
  - point estimate: 47-48 under most plausible proportions, potentially as
    low as 46 if the validation set is heavily skewed toward the harder
    classes (HR+ and TN). We submit 48 using training proportions as the
    best available proxy.
  - the formula and assumptions must be stated explicitly in the Methods or
    Results text, not just asserted as "BA x 57"

DISCUSSION + CONCLUSION (max half page, ~250 words)
----------------------------------------------------
Para 1 - Answering the research question:
  - Wessels' principle is CONDITIONAL on multi-class structure
  - on the full 3-class aCGH problem, RF outperforms NMC (contradicting
    Wessels' finding on expression data)
  - on the decomposed binary HR+/TN subproblem, NMC outperforms RF
    (consistent with Wessels)
  - the HER2+ class acts as a confounder: its trivial separability inflates
    RF's advantage in the 3-class setting
  - this sensitivity to multi-class structure was not tested by Wessels and
    represents a nuance to the original recommendation
  - feature selector matters less than classifier in both settings (consistent
    with Wessels)

Para 2 - Issues affecting results:
  - limited sample size (n=100, only 68 for Stage 2)
  - discrete CN calls lose fine-grained continuous signal
  - ~10 consistently misclassified samples (defined as >80% misclassification
    rate across all 1000 test appearances in the 200-repeat CV; this threshold
    must be defined on first use in Results, then referenced here)
  - performance ceiling: ceiling analysis on consistently misclassified
    samples revealed no KW features distinguishing them from correctly
    classified samples within either class (p > 0.05 at all significance
    levels), suggesting the BA2 ~0.76 limit reflects irreducible noise in the
    discrete CN representation rather than classifier capacity

Para 3 - Best single biomarker (brief):
  - chr17q12 ERBB2 amplicon: strongest single region, defines HER2+ subtype
  - for HR+/TN discrimination, chr12q and chr5q carry the signal

Para 4 - Future directions (2-3 sentences):
  - integration with expression data for multi-omic classification
  - larger aCGH cohorts to test whether hierarchical NMC advantage generalises
  - investigation of consistently misclassified samples for biological
    discordance vs labelling error
