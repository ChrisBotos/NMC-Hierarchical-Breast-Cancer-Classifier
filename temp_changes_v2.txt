1. NEW FILES CREATED
================================================================================

1.1 code/utils/cv_components.py
    - KruskalWallisSelector(BaseEstimator, TransformerMixin)
        Lifted from KW_pipelines.py. Computes KW H-statistic per feature,
        selects top-k. Stores scores_, ranking_, indices_.
    - ElasticNetSelector(BaseEstimator, TransformerMixin)
        New. Wraps LogisticRegression(penalty='elasticnet', solver='saga',
        multi_class='multinomial') as a feature selector. Fits the model in
        fit(), selects top_k features by sum of |coef_| across classes in
        transform(). Convergence warnings are surfaced via logging.
        Uses class_weight='balanced' on the internal LogisticRegression.

1.2 code/utils/cv_config.py
    - PIPELINE_NAMES: ("kw_nmc", "kw_rf", "en_nmc", "en_rf")
    - TRIAL_GRIDS: Small grids for development.
        KW: k in [5, 20]
        EN: C in [0.01, 0.1, 1.0, 10.0], l1_ratio in [0.1, 0.5, 0.9],
            top_k in [5, 20] -> 24 combinations
    - PRODUCTION_GRIDS: Full grids per research plan.
        KW: k in [5, 10, 15, 20, 30, 50, 75, 100] -> 8 combinations
        EN: C = logspace(-3, 2, 10), l1_ratio in [0.1, 0.3, 0.5, 0.7, 0.9],
            top_k in [5, 10, 20, 50] -> 200 combinations
    - TRIAL_REPEATS = 3, PRODUCTION_REPEATS = 10
    - build_pipeline(pipeline_name, random_state) factory function:
        Constructs sklearn Pipelines for each of the 4 cells.

1.3 code/model_training_phase.py
    - Unified runner. One invocation = one (pipeline, repeat) job = 5 outer folds.
    - CLI: --pipeline {kw_nmc,kw_rf,en_nmc,en_rf} --repeat <int>
           --config {trial,production} --input <path> --clinical <path>
    - Uses sklearn Pipeline + GridSearchCV for ALL four pipelines.
    - Output: fold_results CSV per job with columns:
        pipeline, repeat, outer_fold, balanced_accuracy, best_inner_score,
        best_params, n_features_selected, selected_features, fold_seconds

1.4 Updated code/utils/__init__.py
    - Added re-exports for cv_components and cv_config.

================================================================================
2. KEY DESIGN DECISIONS
================================================================================

2.1 Balanced accuracy remains primary metric (no AUROC).
    Carried forward from temp_changes.txt section 1.1.

2.2 RF hyperparameters are FIXED (not tuned).
    Per research plan: 500 trees, min_samples_leaf=2, no max_depth limit.
    The teammate scripts incorrectly tuned n_estimators/max_depth/min_samples_split.
    This is now corrected: RF has zero tunable hyperparameters.

2.3 class_weight='balanced' on ElasticNet only.
    Applied to the LogisticRegression inside ElasticNetSelector. Not applied to
    RF (fixed config per research plan, and the ~32/36/32 distribution is
    nearly uniform).

2.4 No NearestCentroidWithProba wrapper.
    Since balanced accuracy (not AUROC) is the metric, NMC's predict() suffices.
    No probability outputs needed.

2.5 EN pipeline uses Pipeline + GridSearchCV (not manual loops).
    The teammate EN scripts had 80+ lines of manual inner CV code per script.
    ElasticNetSelector as a transformer enables GridSearchCV to handle all
    inner loop machinery, eliminating manual fold iteration bugs.

2.6 Single (pipeline, repeat) per invocation.
    Enables trivial shell parallelism: run 4 pipelines x N repeats as
    independent jobs.

2.7 Trial vs production configs.
    Trial: small grids for fast iteration (2 KW, 24 EN combinations).
    Production: full grids per research plan (8 KW, 200 EN combinations).
