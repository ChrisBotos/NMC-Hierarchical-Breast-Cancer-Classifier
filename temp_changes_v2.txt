================================================================================
1. NEW FILES CREATED
================================================================================

1.1 code/utils/cv_components.py
    - KruskalWallisSelector(BaseEstimator, TransformerMixin)
        Lifted from KW_pipelines.py. Computes KW H-statistic per feature,
        selects top-k. Stores scores_, ranking_, indices_.
    - ElasticNetSelector(BaseEstimator, TransformerMixin)
        New. Wraps LogisticRegression(penalty='elasticnet', solver='saga',
        multi_class='multinomial') as a feature selector. Fits the model in
        fit(), selects top_k features by sum of |coef_| across classes in
        transform(). Convergence warnings are surfaced via logging.
        Uses class_weight='balanced' on the internal LogisticRegression.
    - NearestCentroidWithProba(NearestCentroid)
        New. Subclass adding predict_proba via softmax of negative Euclidean
        distances to class centroids. Enables AUROC computation for NMC
        pipelines symmetrically with RF's native predict_proba.

1.2 code/utils/cv_config.py
    - PIPELINE_NAMES: ("kw_nmc", "kw_rf", "en_nmc", "en_rf")
    - TRIAL_GRIDS: Small grids for development.
        kw_nmc: k in [5, 20] -> 2 combinations
        kw_rf:  k in [5, 20] x max_features x min_samples_leaf -> 8
        en_nmc: C x l1_ratio x top_k -> 24 combinations
        en_rf:  C x l1_ratio x top_k x max_features x min_samples_leaf -> 96
    - PRODUCTION_GRIDS: Full grids per research plan.
        kw_nmc: k in [5,10,15,20,30,50,75,100] -> 8 combinations
        kw_rf:  k x max_features x min_samples_leaf -> 72
        en_nmc: C(10) x l1_ratio(5) x top_k(4) -> 200 combinations
        en_rf:  C(10) x l1_ratio(5) x top_k(4) x max_features(3) x
                min_samples_leaf(3) -> 1800 combinations
    - TRIAL_REPEATS = 3, PRODUCTION_REPEATS = 10
    - build_pipeline(pipeline_name, random_state) factory function.

1.3 code/nested_cv_2x2_runner.py
    - Unified runner. One invocation = one (pipeline, repeat) job = 5 outer folds.
    - CLI: --pipeline {kw_nmc,kw_rf,en_nmc,en_rf} --repeat <int>
           --config {trial,production} --input <path> --clinical <path>
    - Uses sklearn Pipeline + GridSearchCV for ALL four pipelines.
    - Primary metric: balanced_accuracy (inner CV scoring + outer evaluation).
    - Secondary metric: weighted one-vs-rest AUROC via predict_proba.
    - Output: fold_results CSV per job with columns:
        pipeline, repeat, outer_fold, balanced_accuracy, auroc_weighted,
        best_inner_score, best_params, n_features_selected,
        selected_features, fold_seconds

1.4 Updated code/utils/__init__.py
    - Added re-exports for cv_components and cv_config.

================================================================================
2. KEY DESIGN DECISIONS
================================================================================

2.1 Balanced accuracy is the primary metric.
    Inner CV scoring='balanced_accuracy'. Outer fold evaluation uses
    balanced_accuracy_score. This is the metric used to compare pipelines.

2.2 AUROC is the secondary metric.
    Weighted one-vs-rest AUROC captured per outer fold using predict_proba.
    NearestCentroidWithProba enables symmetric AUROC across all 4 pipelines.
    Reported in the fold results CSV for the paper's discussion of ranking
    quality and probabilistic calibration.

2.3 RF hyperparameters are TUNED via inner CV.
    n_estimators=500 is fixed (more trees is always better). Tuned params:
    - max_features: controls per-tree feature diversity.
    - min_samples_leaf: controls tree regularisation.
    Nested CV eliminates selection bias on the evaluation set, making RF
    tuning methodologically sound even at n=100.

2.4 class_weight='balanced' on both EN and RF.
    Applied consistently to ElasticNetSelector's internal LogisticRegression
    and to RandomForestClassifier in both KW+RF and EN+RF pipelines.
    Accounts for any class imbalance defensively.

2.5 EN pipeline uses Pipeline + GridSearchCV (not manual loops).
    ElasticNetSelector as a transformer enables GridSearchCV to handle all
    inner loop machinery.

2.6 Single (pipeline, repeat) per invocation.
    Enables trivial shell parallelism.

2.7 Trial vs production configs.
    Trial: fast iteration. Production: full grids per research plan.

3. CHANGES FROM TEAMMATE SCRIPTS
================================================================================

3.1 RF hyperparameters corrected [CHANGED]
    BEFORE: Tuned n_estimators, max_depth, min_samples_split (wrong params).
    AFTER:  n_estimators=500 fixed. Tune max_features, min_samples_leaf.
            class_weight='balanced' added.
    REASON: max_features and min_samples_leaf are the meaningful regularisation
            knobs for RF. Nested CV makes tuning safe.

3.2 EN_RF joint grid restructured [CHANGED]
    BEFORE: 960 combinations (wrong RF params in the grid).
    AFTER:  Trial 96, production 1800 combinations (correct RF params).

3.3 All four pipelines use Pipeline + GridSearchCV [UNIFIED]
    BEFORE: KW used Pipeline+GridSearchCV; EN used manual loops.
    AFTER:  All four use Pipeline+GridSearchCV.

3.4 class_weight='balanced' added to EN and RF [NEW]
    BEFORE: No class_weight anywhere.
    AFTER:  Both EN (inside ElasticNetSelector) and RF use class_weight='balanced'.

3.5 NearestCentroidWithProba replaces NearestCentroid [NEW]
    BEFORE: NearestCentroid with predict() only.
    AFTER:  NearestCentroidWithProba with predict() + predict_proba().
            Enables AUROC computation for NMC pipelines.

3.6 AUROC captured per fold [NEW]
    BEFORE: Only balanced_accuracy stored.
    AFTER:  Both balanced_accuracy and auroc_weighted stored in fold CSV.
