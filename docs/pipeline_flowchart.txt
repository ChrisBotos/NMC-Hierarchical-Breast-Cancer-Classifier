================================================================================
              CATS Pipeline Flowchart — Breast Cancer Subtype Classification
================================================================================

  Research Question:
  Does Wessels' principle (simple classifier + univariate filtering > complex
  pipelines) hold on discrete aCGH data with 3 classes and feature redundancy?

================================================================================

  INPUT DATA
  ──────────
  Train_call.tsv ──────────> 100 samples x 2834 genomic regions (CN: -1,0,1,2)
  Train_clinical.tsv ──────> 100 sample labels (HER2+: 32, HR+: 36, TN: 32)
  Validation_call.tsv ─────> 57 unlabelled samples x 2834 regions


================================================================================
  PHASE 0: DATA EXPLORATION  [COMPLETE]
================================================================================

  Train_call.tsv + Train_clinical.tsv
          │
          ▼
  ┌─────────────────────────────────────────────┐
  │  Exploration Analyses                        │
  │  ├── Class distribution (balanced)           │
  │  ├── Genome-wide aberration frequency        │
  │  ├── PCA / t-SNE (HER2+ separates)          │
  │  ├── Hierarchical clustering (sil=0.092)     │
  │  ├── Kruskal-Wallis per region               │
  │  │   └── 6 regions pass Bonferroni (chr12/17)│
  │  ├── Spatial correlation analysis            │
  │  │   └── r=0.92 at <0.1 Mb, heavy redundancy│
  │  └── Sample similarity matrix                │
  └─────────────────────────────────────────────┘
          │
          ▼
  KEY FINDINGS:
  • Feature selection is essential (raw space has no cluster structure).
  • Must handle spatial autocorrelation (nearby regions are redundant).
  • HER2+ is easy to separate; HR+ vs TN is the hard boundary.


================================================================================
  PHASE 1: LABEL-FREE REGION MERGING
  Script: code/preprocessing_phase.py
================================================================================

  2834 raw regions (per chromosome)
          │
          ▼
  ┌─────────────────────────────────────────────────────────┐
  │  Greedy one-pass merge per chromosome                   │
  │  Adjacent regions with Pearson r > 0.8 merged into      │
  │  consensus segments. Consensus value = median CN.       │
  │  Label-free (no class labels used) -> no leakage.       │
  │  2834 regions -> ~273 consensus segments (10x reduction)│
  │  Same merge map applied to Validation_call.tsv.         │
  └───────────────────────────┬─────────────────────────────┘
                              │
                              ▼
                  ~273 consensus segments


================================================================================
  PHASE 2: MODEL TRAINING & EVALUATION
  Script: code/model_training_phase.py
================================================================================

  Input: ~273 consensus segments from Phase 1.

  FEATURE SELECTION METHODS (applied inside each CV fold):

  ┌─────────────────────────────┐   ┌─────────────────────────────────────┐
  │   UNIVARIATE: KW top-k     │   │   MULTIVARIATE: Elastic Net         │
  │                             │   │                                     │
  │ 1. Kruskal-Wallis test per  │   │ L1+L2 penalised multinomial         │
  │    consensus segment        │   │ logistic regression                 │
  │ 2. Rank by p-value          │   │ (sklearn LogisticRegression with    │
  │ 3. Select top k segments    │   │  penalty='elasticnet', solver='saga'│
  │                             │   │  l1_ratio controls L1/L2 balance)   │
  │ Tune: k                     │   │                                     │
  │  {5,10,15,20,30,50,75,100}  │   │ Tune: C x l1_ratio (10 x 5 grid)   │
  └─────────────────────────────┘   └─────────────────────────────────────┘

  CLASSIFIER METHODS:

  ┌─────────────────────────────┐   ┌─────────────────────────────────────┐
  │   SIMPLE: NMC               │   │   COMPLEX: Random Forest            │
  │                             │   │                                     │
  │ Nearest Mean Classifier     │   │ 500 trees, min_samples_leaf=2       │
  │ Zero hyperparameters        │   │ Fixed params (not tuned at n=100)   │
  │ Linear decision boundary    │   │ Non-linear, captures interactions   │
  │ Probabilities via softmax   │   │ Native predict_proba()             │
  │ of negative distances       │   │                                     │
  └─────────────────────────────┘   └─────────────────────────────────────┘

  = 4 pipelines: KW+NMC | KW+RF | ENet+NMC | ENet+RF

  CROSS-VALIDATION SCHEME: Stratified 5-fold, repeated 10x (50 fits per cell).
  Feature selection runs INSIDE each fold (no data leakage).
  Scoring metric: weighted one-vs-rest AUROC.

  ┌──────────────────────────────────────────────────────────────────────────┐
  │                        OUTER CV (5-fold x 10 repeats)                    │
  │                                                                          │
  │   For each fold split:                                                   │
  │   ┌────────────────────────────────────────────────────────────────────┐ │
  │   │  80 train samples                        20 test samples           │ │
  │   │       │                                                            │ │
  │   │       ▼                                                            │ │
  │   │  INNER CV (5-fold on train only)                                   │ │
  │   │  ├── Feature selection (on inner train folds)                      │ │
  │   │  ├── Train classifier (on inner train folds)                       │ │
  │   │  ├── Score AUROC on inner validation fold                          │ │
  │   │  └── Pick best hyperparameters (highest mean inner AUROC)          │ │
  │   │       │                                                            │ │
  │   │       ▼                                                            │ │
  │   │  Retrain with best hyperparams on full outer training set          │ │
  │   │       │                                                            │ │
  │   │       ▼                                                            │ │
  │   │  Predict on test fold ───────────────────> fold AUROC              │ │
  │   └────────────────────────────────────────────────────────────────────┘ │
  │                                                                          │
  │   Aggregate: mean AUROC +/- std across 50 folds                          │
  └──────────────────────────────────────────────────────────────────────────┘

  RUN FOR ALL FOUR CELLS OF THE 2x2 GRID:

  ┌──────────────────────────┬───────────────────────┬────────────────────────┐
  │                          │  NMC (simple)         │  Random Forest (cplx)  │
  ├──────────────────────────┼───────────────────────┼────────────────────────┤
  │  Univariate              │  Cell A               │  Cell B                │
  │  (KW top-k)              │  Wessels' prediction: │  Complex model +       │
  │                          │  should win at n=100  │  simple features       │
  ├──────────────────────────┼───────────────────────┼────────────────────────┤
  │  Multivariate            │  Cell C               │  Cell D                │
  │  (Elastic Net)           │  Joint selection +    │  Max complexity,       │
  │                          │  simple model         │  expected to overfit   │
  └──────────────────────────┴───────────────────────┴────────────────────────┘

  OUTPUTS:
  • 2x2 AUROC table (mean +/- std).
  • Confusion matrices per cell.
  • Statistical comparison (Wilcoxon signed-rank on 50 fold AUROCs).
  • Best single biomarker region.
  • Feature importance / selection frequency across folds.


================================================================================
  PHASE 3: FINAL PREDICTION
  Script: code/final_prediction_phase.py

  Select best pipeline from 2x2 AUROC results

          ▼

  │  Train final model on all 100 samples with best      │
  │  hyperparams. Apply Phase 1 merge map to validation. │
  └──────────────────────────┬───────────────────────────┘
                     │
          ┌──────────┴──────────┐
          ▼                     ▼
  ┌──────────────┐    ┌─────────────────────────┐
  │ model.pkl    │    │ Apply to 57 validation   │
  │ (joblib)     │    │ samples                  │
  └──────────────┘    └────────────┬────────────┘
                                   │
                      ┌────────────┴────────────┐
                      ▼                         ▼
              ┌──────────────┐         ┌──────────────┐
              │prediction.txt│         │ estimate.txt │
              │(57 labels)   │         │ (0-57)       │
              └──────────────┘         └──────────────┘
